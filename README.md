## Contents

| Path | Purpose |
| --- | --- |
| `index.html` | Compact biography, selected research/publication, education and contact |
| `style.css` | Responsive light and dark themes |
| `script.js` | Interactive illustration and copy controls |

## Development

No build step or dependencies. Serve this directory with `python3 -m http.server 8000` and visit http://localhost:8000/.

GitHub Pages publishes the root of the `main` branch. Changes pushed to that branch update the site.
